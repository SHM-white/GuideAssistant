# 后续优化路线图

- [x] 快捷键支持 Ctrl/Alt/Shift/Win 组合键；保留同键多操作以及已有单键绑定
- [x] 游戏前台快捷键作用域、全局继承/独立覆盖与重复绑定提示（重复绑定是合法配置）
- [ ] 游戏专属工作区：自动切换布局、快捷键、攻略和播放器进度
- [x] B站视频时间戳收藏：使用现有收藏夹，保存含 t=秒数的视频 URL
- [ ] 字幕全文检索、视频章节导航和跨平台时间戳支持
- [ ] 工具栏及字幕/方向悬浮窗的可视化布局编辑、多显示器/DPI 适配
- [ ] 后台标签 WebView2 资源管理、浏览器导航和站点适配器重构
- [ ] 统一设置持久化、自动备份及导入导出

- [ ] 更好的方向解析及游戏特定词库
- [ ] 原生 WinUI/WPF 与 WebView2 的集成测试和长时间运行测试
