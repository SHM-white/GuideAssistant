# 后续优化路线图

本 PR 优先恢复稳定性和可构建性。以下改进在后续 PR 分批进行，**稳定后才发布 Release**。

## 基础体验
- [ ] 快捷键支持组合键、游戏专属作用域和重复绑定提示；**同一个按键同时绑定多个操作是设计特性，必须保留**
- [ ] 游戏专属工作区：自动切换布局、快捷键、攻略和播放器进度
- [ ] 攻略时间戳收藏、字幕全文检索、视频章节导航
- [ ] 工具栏及字幕/方向悬浮窗的可视化布局编辑、多显示器/DPI 适配
- [ ] 后台标签 WebView2 资源管理、浏览器导航和站点适配器重构
- [ ] 统一设置持久化、自动备份及导入导出

## 字幕与游戏辅助
- [ ] JS 音频采集从 ScriptProcessor 迁移到 AudioWorklet
- [ ] 实现进程级音频采集，避免系统 Loopback 混入游戏及聊天音频
- [ ] 更好地处理音频格式、播放状态变化、语音识别取消与线程队列
- [ ] 字幕会话在网页离开/切换标签页时显式停止，避免跨视频残留
- [ ] 区分字幕中的世界方位与玩家相对方向，不再将“正前方”默认理解为北
- [ ] 更好的方向解析及游戏特定词库
- [ ] 原生 WinUI/WPF 与 WebView2 的集成测试和长时间运行测试

## 发布
- [ ] Windows x64 免安装 ZIP，保留签名 MSIX 侧载包
- [ ] 自动化数据库迁移、按键多重绑定及 WebView2 播放器回归测试
- [ ] 补充安装指引、截图及资源占用基准
